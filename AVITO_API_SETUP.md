## 🔑 Регистрация в Avito API

### Шаг 1: Переход на портал разработчиков

1. Откройте браузер и перейдите на [Avito API Developer Portal](https://developers.avito.ru/)
2. Нажмите кнопку "Регистрация" или "Войти"
3. Войдите в свой аккаунт Avito или создайте новый

### Шаг 2: Подтверждение аккаунта

1. Подтвердите ваш email адрес
2. Заполните профиль разработчика:
   - Имя и фамилия
   - Название компании (если есть)
   - Описание деятельности
   - Контактная информация

## 🚀 Создание приложения

### Шаг 1: Создание нового приложения

1. В личном кабинете разработчика нажмите "Создать приложение"
2. Заполните форму:
   - **Название приложения**: `PS-CRM Avito Integration`
   - **Описание**: `Тестовое приложение для интеграции с API Avito`
   - **Категория**: Выберите подходящую категорию
   - **Веб-сайт**: `https://ps-crm.ru`

### Шаг 2: Настройка приложения

1. В настройках приложения найдите раздел "API"
2. Включите необходимые разрешения:
   - ✅ Чтение сообщений
   - ✅ Отправка сообщений
   - ✅ Чтение чатов
   - ✅ Webhook уведомления

## 🔐 Получение ключей

### Шаг 1: Получение Client ID и Client Secret

1. В настройках приложения найдите раздел "API ключи"
2. Скопируйте:
   - **Client ID** - идентификатор приложения
   - **Client Secret** - секретный ключ

### Шаг 2: Получение Access Token

1. Перейдите в раздел "Токены доступа"
2. Нажмите "Создать токен"
3. Выберите необходимые разрешения
4. Скопируйте **Access Token**

### Шаг 3: Настройка переменных окружения

Отредактируйте файл `.env`:

```env
# Avito API Configuration
AVITO_CLIENT_ID=your_client_id_here
AVITO_CLIENT_SECRET=your_client_secret_here
AVITO_ACCESS_TOKEN=your_access_token_here
AVITO_WEBHOOK_SECRET=your_webhook_secret_here

# Flask Configuration
FLASK_SECRET_KEY=your_secret_key_here
FLASK_ENV=production

# Server Configuration
HOST=127.0.0.1
PORT=8000
```

## 🔗 Настройка webhook

### Шаг 1: Настройка webhook URL

1. В настройках приложения найдите раздел "Webhook"
2. Добавьте webhook URL: `https://ps-crm.ru/webhook/avito`
3. Выберите события для уведомлений:
   - ✅ Новые сообщения
   - ✅ Изменения в чатах
   - ✅ Статус сообщений

### Шаг 2: Получение webhook secret

1. В настройках webhook найдите "Webhook Secret"
2. Скопируйте секретный ключ
3. Добавьте его в файл `.env` как `AVITO_WEBHOOK_SECRET`

### Шаг 3: Тестирование webhook

1. Нажмите "Тест webhook" в настройках
2. Проверьте, что в логах приложения появилось уведомление
3. Убедитесь, что статус webhook "Активен"

## 🧪 Тестирование подключения

### Шаг 1: Проверка статуса API

1. Запустите приложение
2. Откройте в браузере: `https://ps-crm.ru`
3. Проверьте индикатор статуса в правом верхнем углу
4. Должен быть зеленый индикатор "Подключено к API"

### Шаг 2: Тестирование получения сообщений

1. Перейдите на вкладку "Сообщения"
2. Нажмите "Обновить"
3. Проверьте, что сообщения загружаются без ошибок

### Шаг 3: Тестирование отправки сообщений

1. Перейдите на вкладку "Отправить"
2. Введите ID чата (можно получить из вкладки "Чаты")
3. Введите тестовое сообщение
4. Нажмите "Отправить"
5. Проверьте, что сообщение отправлено успешно

### Шаг 4: Тестирование webhook

1. Отправьте сообщение через Avito в чат с вашим приложением
2. Перейдите на вкладку "Логи"
3. Проверьте, что появилась запись о получении webhook
4. Перейдите на вкладку "Сообщения" и убедитесь, что новое сообщение отображается

## 🔧 Устранение неполадок

### Проблема: "Ошибка подключения к API"

**Возможные причины:**
- Неверный Access Token
- Истек срок действия токена
- Недостаточно прав у приложения

**Решение:**
1. Проверьте правильность Access Token в файле `.env`
2. Обновите токен в настройках приложения
3. Проверьте права доступа приложения

### Проблема: "Webhook не работает"

**Возможные причины:**
- Неверный webhook URL
- Проблемы с SSL сертификатом
- Неверная подпись webhook

**Решение:**
1. Проверьте доступность URL `https://ps-crm.ru/webhook/avito`
2. Убедитесь, что SSL сертификат действителен
3. Проверьте правильность webhook secret

### Проблема: "Не удается отправить сообщение"

**Возможные причины:**
- Неверный ID чата
- Недостаточно прав для отправки
- Ошибка в API запросе

**Решение:**
1. Проверьте правильность ID чата
2. Убедитесь, что у приложения есть права на отправку сообщений
3. Проверьте логи приложения на наличие ошибок

## 🔒 Безопасность

### Рекомендации по безопасности:

1. **Храните ключи в безопасности**:
   - Никогда не коммитьте файл `.env` в git
   - Используйте переменные окружения в продакшене
   - Регулярно обновляйте токены

2. **Настройте firewall**:
   ```bash
   sudo ufw allow 80
   sudo ufw allow 443
   sudo ufw enable
   ```

3. **Регулярно обновляйте систему**:
   ```bash
   sudo apt update && sudo apt upgrade
   ```

4. **Мониторинг логов**:
   - Регулярно проверяйте логи приложения
   - Настройте алерты на критические ошибки
   - Ведите журнал всех API запросов

## 📊 Мониторинг

### Полезные команды для мониторинга:

```bash
# Статус приложения
sudo systemctl status avito-api-test

# Просмотр логов в реальном времени
sudo journalctl -u avito-api-test -f

# Проверка использования ресурсов
htop

# Проверка сетевых соединений
netstat -tulpn | grep :8000

# Проверка SSL сертификата
sudo certbot certificates
```

### Автоматическое обновление SSL:

```bash
# Добавьте в crontab для автоматического обновления
sudo crontab -e

# Добавьте строку:
0 12 * * * /usr/bin/certbot renew --quiet
```
