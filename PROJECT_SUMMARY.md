# 📋 Сводка проекта: Тестовое приложение API Avito

## 🎯 Цель проекта

Создание полнофункционального веб-приложения для тестирования интеграции с API Avito, позволяющего получать и отправлять сообщения через веб-интерфейс.

## 🏗️ Архитектура проекта

### Backend (Python/Flask)
- **app.py** - Основное Flask приложение с API endpoints
- **avito_api.py** - Модуль для работы с API Avito
- **requirements.txt** - Python зависимости

### Frontend (HTML/CSS/JavaScript)
- **static/index.html** - Главная страница с современным UI
- **static/style.css** - Стили с адаптивным дизайном
- **static/script.js** - Интерактивность и API взаимодействие

### Конфигурация и документация
- **setup.sh** - Автоматический скрипт настройки сервера
- **README.md** - Подробная документация
- **QUICK_START.md** - Быстрый старт
- **AVITO_API_SETUP.md** - Инструкция по получению API ключей
- **.env.example** - Пример переменных окружения
- **.gitignore** - Исключения для git

## 📊 API Endpoints

### Основные endpoints
- `GET /api/status` - Статус подключения к API
- `GET /api/messages` - Получение списка сообщений
- `GET /api/messages/{id}` - Получение конкретного сообщения
- `GET /api/chats` - Получение списка чатов
- `GET /api/chats/{id}` - Получение информации о чате
- `POST /api/send` - Отправка сообщения
- `PUT /api/messages/{id}/read` - Отметка как прочитанное
- `POST /api/upload` - Загрузка файла
- `GET /api/logs` - Получение логов

### Webhook endpoints
- `POST /webhook/avito` - Обработка webhook от Avito
- `GET /webhook/avito` - Верификация webhook URL

## 🔄 Жизненный цикл сообщения

1. **Получение webhook** - Avito отправляет уведомление о новом сообщении
2. **Обработка данных** - Приложение парсит и валидирует данные
3. **Сохранение в логах** - Запись о событии сохраняется
4. **Отображение в UI** - Сообщение появляется в списке
5. **Отправка ответа** - Пользователь может ответить через интерфейс
6. **API запрос** - Сообщение отправляется через API Avito
